## 0. V1.1 视觉基调（按参考截图重做，优先级高于下文旧章节）

参考截图的观感来自四件事，本作逐一落地：

### 0.1 倾斜的菱形车场

- 整个 8×8 棋盘做一次 **-22° 刚体旋转**（`ParkingGeometry.ROTATION_DEGREES`），
  绘制时 `canvas.rotate()`，触摸时做一次逆旋转——纯旋转不改长度，描边与命中区无需补偿。
- 旋转后棋盘外接盒决定格子尺寸：`cell = min(可用宽, 可用高) / (6·cos22° + 6·sin22°) ≈ /7.81`。
  360dp 宽的屏上格子约 42dp，比正交布局更大更好点。
- 乘客队列与接客区**不参与旋转**，是水平的两条横带，宽度 = 旋转后外接盒宽度。

### 0.2 车辆的立体感（自下而上 5 层）

| 层 | 画法 | 目的 |
|----|------|------|
| 投影 | 车身矩形向右下偏移 `3dp × scale`，`#29000000` | "放在地上"的体积感 |
| 车身 | 角色色圆角矩形，圆角 = `min(w,h) × 0.3` | 主体 |
| 车顶高光 | 与白混合 30% 的浅色块，占长轴 60%、短轴 64%，**往车头方向偏移** | 读出顶光与车头 |
| 前挡风 | 与黑混合 32% 的深色带，紧贴车顶高光的车头一侧 | 强化"车头在哪" |
| 箭头 | 白色填充 + 深色描边**双绘**，占短轴 46% | 方向，任何色块上都可辨识 |

再加一圈 `game_parking_vehicle_stroke` 描边。移除模式下整车放大 1.06 倍代替高亮描边。

### 0.3 顶部两条横带

- **乘客队列（46dp）**：左侧一块 54dp 宽的深色"计数牌"（大数字 + `LEFT` 小字），
  右侧是彩色小人（圆头 + 圆角身体，同色成团，组间 9dp）；队首组下方一条 2.5dp 主题色下划线。
  超过 14 个用 `+N` 表示。
- **接客区（62dp）**：4 个虚线圆角车位；停了车的位子画一辆横置小车（宽 0.8 × 车位宽，高 0.5 × 车位高）。

### 0.4 底部道具栏

三个 **48dp 高的黄色胶囊按钮**（`parking_prop_bg` / `parking_prop_stroke` / `parking_prop_text`），
圆角 18dp，文字带剩余次数：`排序 ×1` / `刷新` / `移除 ×1`。
顶栏左侧是一个同风格的**分数胶囊**（对应截图左上角的金币位）。

### 0.5 色板（8 色）

| idx | 浅色 | 暗色 | idx | 浅色 | 暗色 |
|-----|------|------|-----|------|------|
| 0 红 | `#E53935` | `#EF5350` | 4 紫 | `#8E24AA` | `#CE93D8` |
| 1 蓝 | `#1E88E5` | `#64B5F6` | 5 粉 | `#EC407A` | `#F48FB1` |

## 1. 设计原则（沿用壳层 4 条，本作各加一句落地约束）

| 原则 | 本作的落地约束 |
|------|---------------|
| **沉浸优先** | 游戏页不出现底部导航栏（用 Fragment destination 覆盖）；棋盘占据全部剩余高度 |
| **令牌驱动，零硬编码** | 所有颜色必须来自 `values(-night)/game_colors.xml`，**Java 中不出现任何 `0xFF` 字面量** |
| **形状先于颜色** | 客用车 = 竖直 + ↑；障碍车 = 横向 + ←/→。去色后 100% 可玩 |
| **拇指优先** | 三个道具按钮放在**底部**，棋盘上方区域只读（乘客 / 接客区不可点） |

> **琥珀在浅色主题下 2.1:1 不达标**（与 `docs/04-ui-spec.md` 中 O 型方块同一问题）。

### 2.3 无障碍校验

- 全部角色色对画布底色：见 2.1 表格，琥珀靠描边补偿
- 箭头（图形）白填充 + 深色描边：对任何角色色 ≥ 3:1 ✅
- 障碍车 `#90A4AE` + 深色描边：与彩色车**色相明显分离**（低饱和） ✅
- 触控目标：格子最小 34dp，命中区外扩到 44dp ✅

## 4. 组件规格

### 4.1 乘客（小人）

- 画法：**一个圆头 + 一个圆角矩形身体**，高 ≈ `queueH × 0.72`，居中于队列条
- 间距：乘客之间 3dp；**同组（同色）乘客间距 1dp**（视觉上成团，表达"这是同一组"）
- 组间距：8dp + 一条 1dp 竖分隔线（`@color/divider`）
- 溢出：队列条最多画 **12 个**乘客圆点；超出的显示 `+N` 文字（`Caption` 样式）
- 队首组：底板加 2dp 高亮下划线（`game_parking_accent`），明确"现在要接的是它"
- 无障碍：`ParkingView` 的 contentDescription 播报"队首 N 位某色乘客"，颜色名走字符串数组

### 4.2 接客位

- 尺寸：宽 = `(棋盘宽 - 6dp×2) / 3`，高 54dp
- 空位：虚线描边（`game_parking_slot_empty`，1dp，`DashPathEffect`）
- 占用：填充车辆颜色 + 描边 + 一辆**缩小版车形**（圆角矩形，长边 = 车位宽 × 0.7）
- 剩余车位提示：无车位时不额外标注（数量本身可见）

### 4.3 车辆

- 圆角矩形，内缩 2dp（与相邻车之间留 4dp 缝隙）
- 填充色：客用车 = 角色色；障碍车 = `game_parking_blocker`
- 描边：`game_parking_vehicle_stroke`，`@dimen/stroke_normal` (1dp)
- **箭头**：居中，尺寸 = `cell × 0.42`；白色填充 + 深色描边双绘（见 2.1 补偿说明）
- 竖直车箭头 ↑；横向车箭头 ← / →
- 选中/拖动中：抬高 1dp 阴影 + 缩放 1.04（沿用壳层 `DRAG_SCALE` 约定）
- 拖动中的合法落点：在车身原位与终点之间画**半透明轨迹条**（`game_parking_accent` 30% 透明度），
  让玩家看清"这辆车只能在这一段里动"

### 4.4 道具按钮

| 按钮 | 默认 | 禁用 | 激活态 |
|------|------|------|--------|
| 撤销 | 可点 | 撤销栈为空 → `enabled=false`，alpha 0.38 | — |
| 刷新 | 可点 | 生成中 → 禁用 | — |
| 移除 | 显示 `移除 ×1` | 次数为 0 → 禁用，文案变 `移除 ×0` | 点击后进入选择态：按钮描边变 `game_parking_accent`，棋盘上**仅障碍车**高亮，顶部提示"点击一辆灰色障碍车移除它" |

> 按钮文案带剩余次数（`移除 ×1`），玩家不用猜。这是本作唯一需要计数展示的道具。

## 5. 微交互与动效

| 场景 | 时长 | 曲线 | 说明 |
|------|------|------|------|
| 车辆移动 | 180ms | easeOutCubic | 位移动画，起点=原位，终点=目标格 |
| 车辆驶出 | 260ms | easeOutCubic | 继续向上滑出停车场顶部，同时 alpha 1→0 |
| 接客浮字 `+N` | 900ms | 上飘 40dp + 淡出 | 出现在接客区上方居中 |
| 队列推进 | 无动画 | — | 直接重绘（避免误导为"队列在动"） |
| 统计数字变化 | 120ms 放大 1.18 → 180ms 回弹 | AccelerateDecelerate | 沿用俄罗斯方块的 `pulse()` |
| 按钮按下 | 系统默认 | — | Material 自带 ripple |

**动效禁忌**：不做"车辆抖动""接客烟花""连击特效"。本作是静谧的解谜，
多余的特效会与 P1（想清楚比手快重要）冲突。

## 6. 状态与空态

| 状态 | 呈现 |
|------|------|
| 生成中（loading） | 棋盘区域显示 `ProgressBar`（居中），道具栏全部禁用 |
| 运行中 | 正常 |
| 通关（SOLVED） | Material 对话框：标题"第 N 关完成"，正文"接走 X 位乘客 · 累计 Y 分"，主按钮"下一关"，次按钮"返回大厅" |
| 卡住（STUCK） | Material 对话框：标题"卡住了"，正文"停车场里已经没有能动的车了"，按钮三选：撤销 / 刷新 / 返回大厅 |
| 接客区满（非阻塞提示） | Snackbar："接客区已满，先接走队首乘客或撤销一步" |
| 移除选择态取消 | Snackbar 消失，按钮描边恢复 |

## 7. 无障碍

- `ParkingView`：`contentDescription` = 动态播报（队首颜色/人数 + 剩余车位 + 剩余乘客）
- 状态变化时 `announceForAccessibility`：接客成功、通关、卡住、接客区满
- 所有按钮均带 `contentDescription`
- 支持系统字体放大到 200%：统计卡文字用 `wrap_content`，棋盘不随字体缩放（棋盘是固定比例图形）
- 尊重"减少动画"系统设置：若开启，位移动画时长降为 0（直接跳到终点）
